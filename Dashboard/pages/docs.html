Getting Started

Follow these steps to install and run Interface on your system.

1

Clone the Repository

Download the source code from GitHub using git.

git clone https://github.com/neveerlabs/Interface.git
cd Interface
2

Install Dependencies

Install the required Python packages and system tools.

# Python dependency
pip install questionary

# Linux system tools (for full feature set)
sudo apt install nmap hostapd dnsmasq wireshark
3

Run Interface

Launch the script with root privileges for full functionality.

sudo python3 app.py
4

Windows Setup

On Windows, run as Administrator. Some features require additional tools.

# Run as Administrator in CMD or PowerShell
python app.py

Commands Reference

All available tools and their descriptions.

Command Description Platform
Network Scanner Scan local network for active hosts using ARP and nmap. Returns IP, MAC, hostname, and vendor. Linux, WSL
Hotspot Manager Create/stop Wi-Fi hotspot. Configure SSID, password, channel, and DHCP range. Requires hostapd & dnsmasq. Linux
IP Changer Change IP address of a network adapter. Supports static assignment and DHCP release/renew. Linux, Windows
Ping Tools Send ICMP packets to a target host. Configurable count, interval, and packet size. All
Wireshark Launch Wireshark GUI or tshark CLI for packet capture on a selected interface. Linux, Windows
Device Info Display system hardware info: CPU, RAM, OS, kernel version, and all network interfaces. All
Check Updates Connect to GitHub to check for new releases and display changelog for pending updates. All
