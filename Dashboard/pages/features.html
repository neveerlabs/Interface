Features

All Features

A complete toolkit for network diagnostics, management, and analysis.

Network Scanner

Discover all active hosts on your local network using ARP and nmap. Retrieves IP addresses, MAC addresses, hostnames, and vendor information for each device.

nmap ARP Linux

Hotspot Manager

Create and manage Wi-Fi access points using hostapd and dnsmasq. Supports custom SSID, password, channel, and DHCP range configuration with real-time client monitoring.

hostapd dnsmasq NAT

Device Info

Display comprehensive hardware and system information including CPU, memory, OS version, kernel, and all network interfaces with their current configuration.

CPU Memory Cross-platform

Ping Tools

Advanced ping utilities with configurable packet count, interval, and size. Includes traceroute, latency graphing, and continuous ping with colored output for quick diagnostics.

ICMP Traceroute Windows / Linux

IP Changer

Change your network interface's IP address, subnet mask, and gateway with a single command. Supports both DHCP and static configuration on Linux and Windows via netsh.

DHCP Static IP netsh

Wireshark Integration

Launch Wireshark or tshark directly from the menu with pre-built capture filters. Capture on any interface and export session data for offline analysis.

tshark pcap Filters

Auto Update Checker

Automatically checks the GitHub repository for new versions on startup. Displays the full changelog for any pending updates and prompts for confirmation before applying.

GitHub API Changelog Auto
